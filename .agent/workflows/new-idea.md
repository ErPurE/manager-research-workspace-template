# 📝 新建灵感工作流

> 前置：先完成 `.agent/core/preflight_checklist.md`，读取 `.agent/runtime/current_task.md`、`.agent/runtime/handoff_note.md`、`.agent/runtime/active_context.md`。
> 执行结束后，刷新 `runtime/current_task.md` 和 `runtime/handoff_note.md`。

## 使用方法

1. 在 `notes/ideas/` 目录下创建新文件，文件名格式: `YYYY-MM-DD-简短标题.md`

2. 使用以下模板填写内容:

```markdown
# 灵感标题

- 📅 日期: [今天日期]
- 🏷️ 标签: #标签1 #标签2
- 🔥 优先级: 高/中/低

## 💭 灵感描述

详细描述你的想法...

## 🤔 为什么重要

这个想法为什么值得记录和追踪...

## 🔗 相关资源

- 相关论文、链接、资料

## 📝 后续行动

- [ ] 下一步要做什么
```

3. 更新 `notes/ideas/README.md` 中的"最近灵感"部分，添加新文件的链接

## 提示

- 灵感不需要完美，先记录再完善
- 定期回顾灵感库，可能会发现新的联系
- 可以将多个相关灵感合并成一个研究方向
