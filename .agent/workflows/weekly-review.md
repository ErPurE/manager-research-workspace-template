# 📅 周回顾工作流

> 前置：先完成 `.agent/core/preflight_checklist.md`，读取 `.agent/runtime/current_task.md`、`.agent/runtime/handoff_note.md`、`.agent/runtime/active_context.md`。
> 执行结束后，刷新 `runtime/current_task.md` 和 `runtime/handoff_note.md`。

## 每周回顾清单

### 1. 回顾本周完成情况

- [ ] 检查 `tasks/todo.json` 中 `group=week` / `group=today` 的完成情况
- [ ] 将 `status=done` 的任务摘要归档到 `tasks/todo_archive.md`，并从 `tasks/todo.json` 移除（避免列表越滚越大）
- [ ] 记录未完成任务的原因

### 2. 整理灵感库

- [ ] 回顾本周新增的灵感 (`notes/ideas/`)
- [ ] 评估哪些灵感值得深入
- [ ] 将有潜力的灵感转化为任务

### 3. 回顾导师指导

- [ ] 检查本周 `guidance/` 中的记录
- [ ] 确认 Action Items 的完成状态
- [ ] 提炼关键建议到汇总中

### 4. 规划下周

- [ ] 整理下周的优先任务
- [ ] 设定本周的 3 个关键目标
- [ ] 预约必要的会议和讨论
