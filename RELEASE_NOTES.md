# Manager Template v2.0.0

This release packages the Manager framework as a clean reusable template.

## Included

- Visual Dashboard.
- Structured todo board.
- Dashboard inbox runtime skeleton.
- API Agent profile UI and safe preview/apply flow.
- Codex, Claude Code, and Copilot bootstrap files.
- `.agent/` rule system with empty runtime and memory.

## Removed

- Personal profile.
- Private todo items.
- Guidance records.
- Research notes.
- Runtime inbox history.
- API keys and API run history.
